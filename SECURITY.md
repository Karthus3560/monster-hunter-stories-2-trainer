# Reporting a security issue

For vulnerabilities in the trainer, save handling, build or release process, use [GitHub's private reporting form](https://github.com/Karthus3560/monster-hunter-stories-2-trainer/security/advisories/new). Do not attach real save files, credentials or private process dumps to a public issue.

For gameplay bugs and compatibility reports, use the public issue templates. Include the game build, trainer version, enabled controls and steps to reproduce. A fixture or redacted diagnostic is preferable to a personal save.

Only the latest public release is maintained. The project does not promise compatibility with multiplayer, altered executables or game versions outside the inspected target.
