## Research references and factual labels

 the author's public feature descriptions at https://drummerscheattables.com/monster-hunter-stories-2-wings-of-ruin/ and structure observations from https://github.com/jim972329667/MonsterHunterStories2 (Debug branch). No external trainer executable, injected library, editor source, cheat-table script or game data is redistributed. Editor code was written independently.
