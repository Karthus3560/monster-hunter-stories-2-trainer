# Kinship Studio v3.5.0

Monster Hunter Stories 2: Wings of Ruin trainer and offline Egg & Gene Studio.
Created by Ghaith Saad Jawad. Unofficial, open source, MIT-licensed code.

Project: https://github.com/Karthus3560/monster-hunter-stories-2-trainer
Downloads: https://github.com/Karthus3560/monster-hunter-stories-2-trainer/releases/latest

1. Run KinshipStudio-v3.5.0-Setup.exe once, then open Kinship Studio from its shortcut. Setup upgrades the same installed app; it does not create version-named copies. The portable ZIP remains available: extract it and run RidersToolkit.exe for manual use.
2. Start Stories 2, load a single-player save and let the trainer connect.
3. Enable your chosen controls. Alt+W opens/closes quick controls; F12 stops live maintenance controls.

Supported target: Steam Windows x64, inspected game build 1.6.1.0. No separate .NET runtime is needed. Other game builds are not promised.

For the overlay, use Windowed or the trainer's Borderless fullscreen helper. True exclusive fullscreen is not supported.

Rainbow/den/workshop settings: close the game, apply settings in Hunt & workshop, then launch. Explore fresh dens/eggs. Restore original game data reverses table changes; F12 does not uninstall them.

Egg Studio: keep Stories 2 closed, choose a manual slot (1–3), Open save, Preview, then Apply/Add. Empty cartons are supported. Every edit and Undo requires a fresh verified backup. Launch the game and load that same slot afterward. Opening/previewing alone does not edit saves.

Settings, profiles, logs, backups and editor journals are stored under your local application-data RidersToolkit folder. Use the app's Save backups screen to manage verified backups.

Verify the downloaded ZIP against SHA256SUMS.txt from the release. The Windows binary is currently unsigned. Source and build instructions are public for inspection and independent builds.

App updates: Profiles & hotkeys → Check for updates → Download update → Restart & update. Your profiles, theme and backups stay in place. Finish current operations and close Egg Studio before restarting. Code signing is separate from updating: the public files remain unsigned until a trusted publisher certificate/service is provisioned.
