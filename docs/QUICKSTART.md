# Play with Kinship Studio

1. Download `KinshipStudio-Launcher-1.1.0-Setup.exe` from the [native release](https://github.com/Karthus3560/monster-hunter-stories-2-trainer/releases/tag/studio-v1.1.0).
2. Close the game and launcher, then install.
3. Open **Kinship Studio - Play Stories 2** and choose **Play with Studio**.
4. Wait for Studio is ready, then open **Camp → page 2 → Kinship Studio**.

Use a supported Windows x64 Steam installation (tested game 1.6.1). Browse can locate it if detection fails. No separate runtime is needed. Use Inventory for settings, profiles and save backups. Close the game and launcher before updating/uninstalling. Your personal settings and backups remain.

This is the new in-game mod, separate from the [older desktop trainer](DESKTOP-TRAINER.md). Do not run both together. See the [main guide](../README.md) for limits, troubleshooting and checksums.
